# Tether: prototype

Flipkart APM '29 case submission, Prompt 2 (AI agents in 2040)
Utkarsh Gangwar · 2023CH10772 · IIT Delhi

Tether is an independent auditor for your personal AI agent. It reads what your agent did, checks it against goals you set in your own words and against the open market, and flags only what needs your attention.

## Run it

Open `index.html` in any browser. No install or build step; plain HTML, CSS and JS.

On a wide screen, the steps on the left walk through the flow:

1. Connect your agent (Tether can read its actions, never act)
2. Write your charter
3. Read the weekly digest
4. Open a decision receipt
5. Check a drift alert
6. Choose what needs your OK, and export your profile to switch agents

All data is illustrative.
